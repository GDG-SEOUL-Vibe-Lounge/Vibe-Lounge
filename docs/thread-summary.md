# 운영팀 스레드 요약 (#devfestseoul-2026, 프로그램 및 운영 준비)

> 기간: 2026-10-27 ~ 2026-11-24, 정리 기준: 스레드 화면 녹화

## 1. 프로그램 목표 (Dayoung, 10/27)

- 참여자들이 세션/핸즈온을 듣지 않을 때에도 충분히 즐길 수 있는 요소를 만든다.
- 여러 세션을 다양하게 즐길 수 있도록 유도한다.
- 참가자 간 네트워킹 시간을 만든다.
- 행사 테마가 보여질 수 있는 재밌는 요소를 만든다.

## 4. Bug Museum 운영 방식 (11/19~20)

1. 사연 모집: 1인당 최대 **2개**
2. 공개 방식: 제출 즉시 공개, 문제 시 운영진 숨김 처리, 작성자 **닉네임** 표시(중복 허용)
3. 투표 방식: 별도 투표 없이 좋아요 수로 순위 (늦게 낸 사연이 불리한 점은 감안)
4. 프리퀀시: 사연 제출 시 1개 (2개 내도 1개), 프리퀀시 관련은 채널에서 나연님과 추가 논의
5. 참가자 식별: 티켓 구매 계정으로만 참여 → 구매 목록으로 validate / 티켓 구매 페이지 UID 정보 확인 중
